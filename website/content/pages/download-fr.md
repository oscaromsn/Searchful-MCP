Télécharger DocFetcher {{ APP_VERSION }}
========================================

Cliquez sur l'un des liens du tableau ci-dessous pour télécharger DocFetcher {{ APP_VERSION }}, la dernière version de DocFetcher. Cliquez sur « exe » si vous ne savez pas quel lien choisir.

Exigences minimales :

- Windows 7 SP1 ou version ultérieure, 64 bits uniquement
- Linux avec GTK3, 64 bits uniquement
- macOS 11 ou version ultérieure

À partir de DocFetcher 1.1.26, il n'est plus nécessaire d'installer un environnement d'exécution Java.

La principale différence entre les versions non portables et portables est que les premières stockent leurs index et paramètres dans votre dossier personnel, tandis que les secondes les stockent dans le dossier de l'application.

Pour une liste des modifications par rapport aux versions précédentes, consultez le [changelog](https://sourceforge.net/p/docfetcher/wiki/ChangeLog/).

Pour recevoir un e-mail de notification lorsqu'une nouvelle version de DocFetcher est publiée, rendez-vous sur [cette page](https://sourceforge.net/projects/docfetcher/), entrez votre adresse e-mail dans le champ "Get an email when there's a new version of DocFetcher" et cliquez sur le bouton "Next".
