Скачать DocFetcher {{ APP_VERSION }}
=====================================

Нажмите на одну из ссылок в таблице ниже, чтобы скачать DocFetcher {{ APP_VERSION }}, последнюю версию DocFetcher. Нажмите "exe", если вы не уверены, какую ссылку выбрать.

Минимальные требования:

- Windows 7 SP1 или новее, только 64-бит
- Linux с GTK3, только 64-бит
- macOS 11 или новее

Начиная с DocFetcher 1.1.26, установка среды выполнения Java больше не требуется.

Основное различие между непортативной и портативной версиями заключается в том, что первая будет хранить свои индексы и настройки в вашей домашней папке, тогда как вторая будет хранить их в папке приложения.

Список изменений по сравнению с предыдущими версиями смотрите в [журнале изменений](https://sourceforge.net/p/docfetcher/wiki/ChangeLog/).

Чтобы получать уведомление по электронной почте о выходе новой версии DocFetcher, перейдите на [эту страницу](https://sourceforge.net/projects/docfetcher/), введите свой адрес электронной почты в поле "Get an email when there's a new version of DocFetcher" и нажмите кнопку "Next".

Другие варианты загрузки
===============
DocFetcher доступен в версии Portable Apps, смотрите [здесь](https://portableapps.com/node/53747).

Для Linux DocFetcher доступен как snap-пакет, смотрите [здесь](https://snapcraft.io/docfetcher).

Более ранние версии можно получить со [страницы загрузки SourceForge.net](https://sourceforge.net/projects/docfetcher/files/docfetcher/).

Информация о том, как получить исходный код, находится на [этой вики-странице](https://sourceforge.net/p/docfetcher/wiki/Source%20code/).
