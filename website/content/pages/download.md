Download DocFetcher {{ APP_VERSION }}
=====================================

Click one of the links in the table below to download DocFetcher {{ APP_VERSION }}, the latest DocFetcher version. Click "exe" if you're not sure which link to click.

Minimum requirements:

- Windows 7 SP1 or later, 64-bit only
- Linux with GTK3, 64-bit only
- macOS 11 or later

Starting with DocFetcher 1.1.26, installing a Java runtime is no longer needed.

The main difference between the non-portable and portable versions is that the former will store their indexes and settings in your home folder, whereas the latter will store them in the application folder.

For a list of changes from previous releases, see the [changelog](https://sourceforge.net/p/docfetcher/wiki/ChangeLog/).

To receive a notification email when a new DocFetcher version is released, go to [this page](https://sourceforge.net/projects/docfetcher/), enter your email address in the "Get an email when there's a new version of DocFetcher" field and click the "Next" button.
