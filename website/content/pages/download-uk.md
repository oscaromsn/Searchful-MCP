Завантажити DocFetcher {{ APP_VERSION }}
=========================================

Клацніть на одне з посилань у таблиці нижче, щоб завантажити DocFetcher {{ APP_VERSION }}, останню версію DocFetcher. Клацніть на "exe", якщо не впевнені, яке посилання вибрати.

Мінімальні вимоги:

- Windows 7 SP1 або пізніша, тільки 64-біт
- Linux з GTK3, тільки 64-біт
- macOS 11 або пізніша

Починаючи з DocFetcher 1.1.26, встановлення середовища виконання Java більше не потрібне.

Основна відмінність між непортативною та портативною версіями полягає в тому, що перша зберігає індекси та налаштування в домашній папці, тоді як остання зберігає їх у папці застосунку.

Для переліку змін у попередніх випусках дивіться [журнал змін](https://sourceforge.net/p/docfetcher/wiki/ChangeLog/).

Щоб отримувати сповіщення електронною поштою про випуск нової версії DocFetcher, перейдіть на [цю сторінку](https://sourceforge.net/projects/docfetcher/), введіть свою адресу електронної пошти в поле "Get an email when there's a new version of DocFetcher" і натисніть кнопку "Next".

Інші завантаження
==================
DocFetcher доступний як версія Portable Apps, дивіться [тут](https://portableapps.com/node/53747).

Для Linux DocFetcher доступний як snap-пакет, дивіться [тут](https://snapcraft.io/docfetcher).

Старіші випуски можна отримати на [сторінці завантажень SourceForge.net](https://sourceforge.net/projects/docfetcher/files/docfetcher/).

Як отримати вихідний код, пояснюється на [цій сторінці вікі](https://sourceforge.net/p/docfetcher/wiki/Source%20code/).
